# 지도 중심 탐색 계약

2026-10-04. 교사·학교·교육청 담당자가 지역에서 사례를 찾고 원문 근거를 확인하는 공개 화면이다. 정적 HTML/CSS/ES modules와 기존 v3 공개 데이터 계약을 유지한다.

- 1024px 이상: 지도 55%, 사례 목록·상세 45%. 상세는 목록 자리를 사용하고 지도는 유지한다.
- 1024px 미만: 조건 없는 첫 방문은 지도, 필터·사례 직접 URL은 목록·상세. 지도·목록 선택 자체는 URL에 추가하지 않는 임시 화면 상태다. 지역 선택, 검색·필터 적용, 비교표 선택은 목록으로 연결한다.
- 지도 집계는 현재 검색·필터에서 지역 조건만 제외한다. 목록은 지역 조건까지 적용하므로 선택 지역의 지도 건수와 일치한다. 범례는 전체 사례의 최대 지역 건수를 5구간으로 나눈 고정 범위이며 0건을 분리한다. 필터마다 색상 척도를 다시 계산하지 않는다.
- SVG 라벨은 행정구역 이름과 건수다. 지도·목록 모두 75개 사례만 집계하며 160개 보조 참고 자료는 연구 부록에 보존한다. 등록 지역은 실제 행사 장소나 활동 규모·순위를 입증하지 않는다.
- 지역 비교 탭은 전체 공개자료 기준임을 표시한다. 선택 시 기존 탐색 조건을 선택한 지역·카테고리로 교체한다.
- 상세는 운영 확인 상태와 사례별 한계의 펼침 항목을 원문 링크 앞에 남긴다. 긴 근거 원문은 펼쳐서 온전히 확인한다. 추가 검토 정보와 출처 ID는 접어서 제공한다. 목록에서 연 상세를 닫으면 노출 건수, 스크롤과 카드 포커스를 복원한다.
- 지도 장애는 지역 버튼으로 대체한다. 공개 데이터 실패는 부분 자료를 표시하지 않고 재시도 버튼을 제공한다.

신규 자료 수집·사실 승인, 장소 핀, 로그인·저장 기능, URL 스키마 변경은 이번 개편에 포함하지 않는다. 운영 상태와 근거의 신뢰도는 별개이며 기존 `needs_review` 판정은 유지한다.

검증: 모델 집계·초기 화면 단위 테스트, 5개 Playwright 브라우저의 지도/검색/상세/복원/오류/접근성 시나리오, 320–1440px 및 1024px 경계 화면, 전체 `npm run verify:release`. 사람의 사용성 평가나 사실 검토 완료를 의미하지 않는다.
