# 지도 중심 탐색 계약

2026-10-04. 교사·학교·교육청 담당자가 지역에서 사례를 찾고 원문 근거를 확인하는 공개 화면이다. 정적 HTML/CSS/ES modules와 기존 v3 공개 데이터 계약을 유지한다.

## 화면과 패널

- 첫 화면은 헤더를 제외한 창 높이와 화면 너비를 채우는 지도 작업공간이다. 제목·검색·지역·필터·보기 전환을 같은 배경 위에 배치한다. 요약·대표 사례는 아래로 스크롤해 본다. 브라우저 전체 화면 권한은 사용하지 않는다.
- 1024px 이상: 조건 없는 첫 방문은 패널을 닫는다. 지역 선택·검색·필터 적용·사례 보기로 오른쪽 400px 패널을 열고 지도를 남은 공간에 맞춘다. 목록·상세는 같은 패널을 사용하며 내부에서 스크롤한다.
- 1024px 미만: 목록은 헤더를 제외한 창 높이의 절반을 차지하는 비모달 하단 패널이다. 위쪽 지도와 검색은 계속 조작할 수 있다. 목록 확대/지도 함께 보기 버튼으로 탐색 영역 전체 높이와 절반 높이를 전환한다. 540px 이하의 짧은 화면에서는 목록을 전체 높이로 열며 지도 복귀를 제공한다.
- 모바일 목록을 열면 하단 범례·날짜 줄을 접어 카드 공간을 확보한다. 패널을 닫으면 복원한다. 공개자료 기준과 운영 미확인 안내는 지도 하단·사례 상태·아래 요약에 표시한다.
- 패널 닫기는 조건을 보존한다. 상세 뒤로 가기는 목록의 노출 건수·스크롤·카드 포커스·확대 상태를 복원한다. 상세에서 패널 전체를 닫으면 URL의 사례 선택만 해제한다. 필터·사례 직접 URL은 해당 목록·상세를 연다. 패널 열림/확대는 URL에 추가하지 않는 임시 상태다.
- 지역 비교는 작업공간을 비교 화면으로 전환한다. 전체 공개자료 기준·탐색 필터 미적용을 명시하며 시·도 공식 순서를 유지한다. 항목 선택 시 기존 탐색 조건을 선택한 지역·카테고리로 교체하고 목록으로 연결한다.

## 검색과 근거

- 검색·지역은 바로 적용한다. 필터는 모든 화면에서 모달 대화상자로 열고 초안의 결과 건수를 미리 표시한다. 결과 보기로 한 번에 적용하며 취소·닫기·Escape는 기존 조건과 URL을 보존한다. 초기화도 적용 전까지 초안이다.
- 지도 집계는 검색·필터에서 지역 조건만 제외한다. 목록은 지역 조건까지 적용하므로 선택 지역의 지도 건수와 일치한다. 범례는 전체 사례의 최대 지역 건수를 5구간으로 나눈 고정 범위이며 0건을 분리한다. 필터마다 색상 척도를 다시 계산하지 않는다.
- SVG는 도형·지역 라벨·연결선·라벨 선택 영역 전체를 포함해 맞춘다. 지역 이름과 건수는 행정구역 요약이며 장소 핀이 아니다. 지도·목록 모두 83개 사례만 집계하고 160개 보조 참고 자료는 연구 부록에 보존한다. 실제 활동 규모·순위나 정확한 개최 위치를 뜻하지 않는다.
- 상세는 운영 확인 상태와 사례별 한계의 펼침 항목을 원문 링크 앞에 남긴다. 긴 근거 원문은 온전히 확인하며 추가 검토 정보와 출처 ID는 접어서 제공한다.
- 지도 장애는 자동으로 펼친 17개 지역 버튼과 지역 선택으로 대체한다. 공개 데이터 실패는 부분 자료를 표시하지 않고 재시도 버튼을 제공한다.

## 디자인과 검증

블랙·네이비 배경, 시안 탐색 강조, 라임 선택 표시와 앰버 검토 상태를 유지한다. 지도 선택은 밀도 채움색을 보존하며 테두리와 라벨로 표시한다. CSS/SVG 장식만 사용하며 외부 폰트·지도 SDK·새 런타임 의존성은 없다. 연구 페이지 디자인과 데이터·URL 계약은 변경하지 않는다.

키보드 지도 선택, 44px 조작 영역, 포커스 복원과 모션 감소 설정을 유지한다. 검증은 집계·패널 상태 단위 테스트, 5개 Playwright 브라우저의 지도/검색/필터 초안/상세/복원/비교/오류/접근성 시나리오, 320–1440px와 1024px 경계·짧은 가로 화면, 지도 라벨 포함 여부 및 전체 `npm run verify:release`로 수행한다. 사람의 사용성 평가나 사실 검토 완료를 의미하지 않는다.
